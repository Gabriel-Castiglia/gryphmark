Vigía @VERSION@

Write Markdown visually and see it exactly as GitHub shows it. When another program, such as an AI assistant, changes the open file, Vigía shows the new text at once.

Requirements: macOS 15 or later on Apple silicon (arm64). There is no build for Intel Macs.

The installer puts Vigía in the Applications folder. If an earlier version is installed, it is replaced and its settings are kept.
